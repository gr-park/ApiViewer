      URL 분석 추출
      

        레포지토리 선택
        

      

    


    
    

      상단에서 레포지토리를 선택하세요. 여러 개를 선택하면 선택된 레포만 순차 추출됩니다. (설정값 기반)
      고급(선택)에서 URL 프리픽스/상수치환만 이번 실행에 한해 오버라이드할 수 있습니다.
    

    

      0개 레포 선택됨 — 기본값은 레포 설정을 사용합니다.
    

    

      

        선택 레포 목록
        
      

      

      

        

          고급 오버라이드(이번 실행만): URL 경로 프리픽스 / 상수 치환만 레포별로 변경할 수 있습니다.
          빈 값이면 레포 설정값이 그대로 적용됩니다.
        

        

      

    


    
    

      
    

  


  

    

      

        
        단건추출 및 디버깅
        JavaParser 단건 파싱 · TS 정규식 폴더 스캔
      

      
    


    

      

        

          🔧 단건 JavaParser 파싱 (주로 디버그 목적)
        

        

          
          
          
          
        

        

          레포를 고르지 않아도 됩니다. 상대경로만 쓸 때는 상단에서 레포 1개를 선택하거나, 등록된 레포 ROOT_PATH가 포함된 전체 절대경로를 붙여넣으세요.
          DB 반영은 결과 모달에서 저장할 레포를 골라 실행합니다. 프리픽스·상수 치환은 저장 시 선택한 레포(및 고급 오버라이드)를 따릅니다.
          파일 선택은 PC의 .java를 지정만 하고, 파싱 실행을 눌렀을 때 서버로 전송·파싱합니다(레포 미선택 시 프리픽스는 비우고 미리보기).
        

      


      

        

          📘 TS(NestJS) 정규식 파싱 (디버그 · 폴더 스캔)
        

        

          
          
          
          
        

        

          NestJS 데코레이터(@Controller + @Get/@Post...) 패턴을 정규식으로 스캔해 URL 개수를 빠르게 점검합니다.
          동적 경로(상수 import, concat, template 등)는 UNRESOLVED로 표시되고 스킵될 수 있습니다.
          결과 모달에서 레포를 선택해 DB 부분 반영도 가능합니다.
        

      

    

  

  


  
  

  

    

      테스트용 의심 키워드 (분석 시 매칭)
    

    

      URL 경로 / 메소드명 / 컨트롤러명 / 파일경로 / 메소드주석 / 컨트롤러주석 / @ApiOperation / @Description 에서
      대소문자 무시 매칭. 영문·숫자만 2~3글자 키워드는 단어 경계(+ 메소드/컨트롤러 camelCase 토큰 일치), 그 외는 부분일치.
      fullUrl 은 도메인 false positive 방지로 제외.
      매칭 결과는 분석현황의 "테스트용 의심" 컬럼에 자동 표시됩니다.
    

    
  

  


  
  

  

    

      경로변수 패턴 일괄 재계산
    

    

      api_path에 포함된 Spring 스타일 경로 변수({version} 등)를 추출해
      파라미터URL 패턴 컬럼에 저장합니다. 추출 시 자동 반영되며, 기존 DB 일괄 보정 시 아래 버튼을 사용하세요.
      (호출 이력 URL과 표시 경로가 다를 수 있음을 구분하는 용도)

        1
        Mock - URL분석데이터 생성
        선택 레포에 URL /mock-test/* 로 시작하는 더미 ApiRecord 생성 · git_history 포함 · 중복 자동 스킵
      

      

        
        
        
        
        
        
      

      

        상태 분포 (9 leaf v2 + 삭제): 사용 55% / 삭제 5% / 검토대상·차단 leaf·차단완료 (나머지)  ·  레포마다 [최소, 최대] 균등 랜덤 건수  ·  호출건수 0 (호출이력은 ② Mock APM)

        전체 수집: 모든 레포에 365일치 MOCK 데이터 생성  ·  선택 수집/삭제: 레포 선택 후 실행  ·  삭제: WHATAP/JENNIFER 데이터는 유지
